# IT Support Ticket Dashboard (Excel)

## Project Overview

This project simulates a basic IT Support ticketing environment using Microsoft Excel.

The dataset contains support tickets with information such as:

* Ticket ID
* User
* Issue Type
* Priority
* Status
* Date Opened
* Date Closed
* Resolution Time

## Features

* Ticket tracking and management
* Resolution time calculation
* KPI Dashboard

  * Total Tickets
  * Open Tickets
  * Closed Tickets
  * Average Resolution Time
* SLA Breach Tracking
* Pivot Tables
* Pivot Charts
* Interactive Slicer Filters

## Key Skills Demonstrated

* Excel Tables
* XLOOKUP
* IF Functions
* COUNTIF
* COUNTA
* AVERAGE
* Pivot Tables
* Pivot Charts
* Conditional Formatting
* Dashboard Design
* Data Cleaning

## Business Use Case

The dashboard helps support teams monitor ticket volume, track resolution performance, identify common issues, and monitor SLA compliance.
